# Шторы и ковёр: дополнение штатного Physics

В PandaSDK ABI 33 нет готового компонента ткани. Это небольшое дополнение существующего
модуля Physics: **Box3D рассчитывает всю физику**, а штатный RuntimeMesh Panda отображает
изгиб исходной модели. Своего решателя физики, интегратора и прохода рендеринга здесь нет.
Это приближение ткани сеткой тонких тел, а не полноценная модель волокон/складок/разрывов.

## Готовая сборка

`Scripts/SMASH LAB/bin/cloth-editor/PandaEditor.app`

Закройте установленный PandaEditor, откройте **эту отдельную сборку** и выберите проект
SMASH LAB. Откройте `Assets/LivingRoom_Prototype.world`, нажмите Reload (Cmd/Ctrl+R), затем
Play. Проверьте толчки по нижней части штор и краям ковра, закреплённый верх штор,
контакты с окружением, несколько Reset по R и Play/Stop. Установленная программа в
`/Applications` не изменялась. Агент редактор/игру не запускал; поведение и вид в игре
не подтверждены.

Один Reload старой установленной программы не добавит компонент: Physics статически
встроен в редактор. Старый редактор оставит шторы статичными, ковёр декоративным;
игровой контроллер выдаст понятную ошибку и сохранит взаимодействие с остальными вещами.
**Не сохраняйте сцену старым редактором:** он не знает `cloth3dComponent` и может удалить
неизвестные поля при сохранении.

## Что добавлено

- Новый сериализуемый `cloth3dComponent` в штатном модуле Physics. Его владелец имеет
  Dynamic Rigidbody3D, а `renderEntity` ссылается на существующий дочерний imported primitive.
- По 3 × 12 ячеек на каждую штору (верхние три неподвижны) и 5 × 4 на ковёр. Всего
  **92 тела и 141 spring Weld joint** в общем мире Box3D; новых ECS-сущностей нет.
- Соседние ячейки соединены штатными гибкими Weld joints: линейная связь удерживает
  полотно вместе, угловая пружина позволяет изгиб. Не соседние ячейки могут сталкиваться;
  соседние пары не сталкиваются друг с другом.
- Исходный imported mesh сохраняет UV, цвета и материал; один раз уплотняются широкие
  треугольники ковра, далее вершины и нормали следуют интерполированным позам ячеек.
  Исходные ассеты, glTF и материалы не изменяются. На Stop исходные компоненты возвращаются,
  ссылки на временные GPU-ресурсы освобождаются обычным AssetHandler.
- Старые неподвижные коллайдеры штор отключаются только в Play, поэтому невидимых
  жёстких копий нет. Физическая основа ковра 12 мм находится под визуальным ворсом;
  полная декоративная толщина 36 мм не превращена в жёсткую ступеньку под столом.
- Raycast возвращает владельца полотна. Существующий Impact Tool распределяет один
  ограниченный толчок между ближайшими свободными ячейками через native Box3D.
- Существующий Reset охватывает эти три владельца. Телепортация возвращает все ячейки,
  обнуляет скорости и пересоздаёт соединения, очищая сохранённые импульсы предыдущего удара.
  Новых тел/мешей/обработчиков при Reset не создаётся.

Упрощения: грубая сетка не воспроизводит мелкие складки, растяжение/разрыв волокон,
трение нитей или точное соприкосновение каждой складки с мебелью. Коллайдеры представляют
тонкую основу; рельеф складок штор и ворс ковра остаются визуальными. Ковёр может немного
повлиять на контакты стоящих на нём ножек — требуется ручная проверка. Параметры остальных
предметов, камеры, света и разрушений сохранены.

## Исходники и повторная сборка

Основа: официальный `toyship-studio/Panda`, commit
`37b843540f0164ea0971fe4c3ec8abff02556b71` (ABI 33, Physics 0.2.0).
Изменения сохранены в `panda-cloth.patch`, включая новый `PhysicsCloth3D.cpp`. Код движка
временной рабочей копии: `/private/tmp/smash-panda-cloth`; он может исчезнуть при очистке
системы, поэтому источником изменений является **патч в этом каталоге**.

Повторная сборка из отдельной рабочей копии указанной версии Panda:

```sh
./EngineExtensions/PhysicsCloth/build_editor.sh /path/to/Panda
```

Скрипт проверяет commit, применяет только приложенный патч и собирает отдельные редактор
и SDK в игнорируемый `Scripts/SMASH LAB/bin/cloth-editor`. Не меняет `/Applications`,
установленный SDK, игровые CMake-файлы или Git index. Не запускает приложение и тесты.
Нужны уже установленные CMake/Clang и Slang из установленного PandaEditor; новый движок
и зависимости не устанавливаются. Путь Slang можно задать через `PANDA_SLANGC_EXECUTABLE`.

Публичный Bamboo API и ABI не менялись: игровая библиотека собирается обычным
`Scripts/SMASH LAB/scripts/build_scripts.sh debug` с прежним PandaSDK. Для будущего
standalone export нужен **SDK из этой отдельной сборки**, включающий дополненный Physics;
экспорт игры в этом задании не выполнялся.
